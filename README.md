# Мультиагентная система потоковой обработки транзакций

Проект выпускной квалификационной работы по теме: Проектирование и исследование мультиагентной системы обработки транзакций на базе виртуальных потоков Java 21 и Apache Kafka.

## Назначение проекта

Исследование характеристик пропускной способности и задержек при использовании легковесных потоков под блокирующей сетевой I/O нагрузкой. Система представляет собой распределенный комплекс взаимодействующих сервисов-агентов, ориентированный на обработку транзакционных потоков без деградации времени ответа при резких всплесках трафика.

## Архитектурная модель

Комплекс проектируется как набор слабосвязанных модулей:

* Входной сервис-агент Gateway: прием внешних HTTP-запросов, проверка контрактов данных и передача событий в распределенный журнал.
* Слой обмена сообщениями: брокер Apache Kafka, разделенный на партиции по идентификаторам клиентов для поддержания строгой последовательности операций.
* Сервис-агент персистентности: асинхронное чтение событий из брокера и проведение идемпотентных записей в PostgreSQL.

## Текущее состояние

В репозитории зафиксирована модульная структура решения и подготовлены базовые конфигурации среды. Проект находится на стадии проектирования интерфейсов взаимодействия и подготовки тестового контура. Непосредственная программная реализация бизнес-логики и сценариев бенчмаркинга ведется в рамках текущего этапа работы над ВКР.

## План инженерных и исследовательских задач

* Проектирование схемы очередей и формата сообщений с поддержкой механизмов дедупликации.
* Реализация компонентов шлюза на Java 21 с включенным режимом Virtual Threads.
* Подготовка контрольных реализаций на базе пулов потоков операционной системы и реактивного подхода через Spring WebFlux.
* Реализация легковесного контрольного модуля на Go для прямого сопоставления с горутинами.
* Проведение серий нагрузочных экспериментов с помощью k6 при конкуренции от 1 000 до 10 000 параллельных сессий.
* Формирование графиков распределения задержек (p90, p95, p99) и профилей утилизации памяти.
